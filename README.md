# 📞 Callclone

A modern voice-calling website that connects people worldwide through real-time audio communication with a simple, user-friendly interface.

## ✨ Features
- 🎙️ Real-time voice calling
- 🌍 Connect with people worldwide
- 📱 Mobile-friendly design
- 🔒 Secure communication

## 🚀 Goal
To make voice communication simple, fast, and accessible to everyone.

## 🛠️ Technologies
Built with modern web technologies.
